Debian and RHEL packages, Docker images (`ghcr.io/llmsyscore/llm-systems-manager:v3.5.1`) and the Homebrew tap (`brew install llmsyscore/tap/llm-systems-manager`) follow the same tag. After upgrading, restart the manager and the alarm engine, and update your agents.

This release fixes the installers and the agent, and smooths the new dashboard: pages hold their shape while they load, and scrollbars are thin and follow the theme.

Try it without installing anything: [demo.llmsysmanager.com](https://demo.llmsysmanager.com).

---

## Spotlight

### Installers

- **Ctrl-C stops cleanly.** Pressing Ctrl-C during an install ends the installer without errors. If you agreed to send an install report, it says the install was cancelled.
- **Updates restart what they stopped.** Pressing Ctrl-C during a server update starts the stopped services again. During the restart step, the updater lists the services you still need to start.
- **Agent install checks.** After starting the agent, the installer waits up to 30 seconds for it to answer and says so if it does not. Running the installer again restarts an agent that is already running.
- **Turning on llama.cpp on a re-run.** Running the agent installer again with `--install-llama` backs up `agent_config.yaml` and turns llama.cpp on in it.
- **GPU hint.** On a machine with a GPU and no inference runtime, the installer now always prints the hint, with commands you can run, and mentions Ollama. `--role system_only` keeps it quiet.

### Agent

- **Back to the packaged llama-server.** Switching from your own llama-server build back to the packaged one restores the service as it was.
- **Large model folders.** A large or network-mounted models folder is no longer read file by file every 15 seconds. New downloads and deletes still show at once.

### Dashboard

- **Pages keep their shape while loading.** The toolbar, the Overall charts and the LLM servers row hold their size until data arrives, so nothing jumps. The LLM servers row says Loading... until the first answer.
- **One-line tiles.** At a glance tiles keep the value, the change and the sub-line on one line; hover for the full text.
- **Thin scrollbars** in the theme's colours, on the dashboard and the alarm engine page.
- **Pill outlines** on the toolbar no longer show breaks in Safari.
- **Tools tab.** When a tool's server is down, the Tools tab shows the dashboard's notice instead of the browser's error page.
- **Report card benchmark** reaches LM Studio through the agent, on whatever address the agent uses.

## Upgrade notes

- **Restart the manager and the alarm engine.** Both changed.
- **Update your agents** with **Update all**.
- **Logs.** The alarm engine's start line and the manager's stop line are now logged as INFO, not WARNING.
- No config changes are needed.
