# Panel kit changes

- 1.0.0: first shared kit, from devtools kit.js plus cloud map and funnel.
- 1.0.0: cloud's behaviour: a ✕ close button and double-click open full size (kitSetFull); full size scales charts through their viewBox and calls onRefit(panel); kitConfigure takes dblSkip (an invalid one is logged and ignored) and the hooks onLegend(panel, chartId), onRefit(root) and holderRows(box) for Copy data; app hook errors go to console.error; chart markers use --c5; stacked bars keep the ts-bar class; data-kit-nosort on a table or any ancestor turns sorting off.
- 1.0.0: cloud's look: cloud theme tokens (the --c1..--c8 and --c-warn set, light --muted #7a8291; --good, --warn, --bad map onto them, light --on-accent #ffffff, darker light-theme --good-text, --bad-text and --warn-text), cloud font stack with no global reset (kit parts zero their own margins, border-box on kit parts only), a fixed .side with .main beside it in a .shell, the one-to-three-column .panels grid with .span2 and .hero (span-N classes removed), the ✕ close button on full-size panels, .top h1 22px, cloud's shadows and small styles, #toast z-index 50.
- 1.1.0: tsHtml threshold lines, a y-axis cap, box-drag zoom with Reset zoom, and kitTsAppend for live points; 1.0 calls render the same; a native dragstart moves a card only inside a [data-cards] box, as the pointer drag already did, and a mouse pointerup clears draggable only on cards in such a box.
- 1.2.0: rankHtml and splitHtml take an optional o.fmt(value) that writes each shown value (for example "0.5 W"); a tsHtml series may carry a legend text (for example "12.4k tokens") that its legend chip shows in place of the summed values, and redraws and live appends keep it; without these options charts and lists render exactly as in 1.1.
- 1.2.1: kitRowFolded(page, rowId, storage) reads a row's saved fold (true, false or null) and kitSetRowFold(row, folded) draws a row folded or open without saving; a kitTable {text, v} cell may carry a title (its hover text); tables without one render as in 1.2.0.
- 1.2.2: tsHtml takes an optional o.gaps 'break' that ends a line at a missing value (null or undefined) instead of drawing it as 0, with a lone value drawn as a dot, the hover showing a dash and kitTsAppend keeping a missing value missing; kitConfigure({fullRedraw: true}) makes "Open full size" redraw a panel's charts at the full-size width with the body's free height shared among them, and a kitFill into a full-size panel (for example a range change) fits its charts to the full-size box again, and closing redraws them at their earlier height. Without these options charts render exactly as in 1.2.1.
- 1.3.0: tsHtml takes optional chart styles for line charts: o.bars 'peak' draws each series as bars (80% of each time slot wide, at least 3 px), faint up to its value and solid up to its avg list, with runs of 0 drawn as a muted line along the bottom; o.split gives each series its own band and scale, named in the band; o.strip names a series drawn as a colour strip on top (stronger colour for higher values, to o.ymax or 100) with o.stripLabel at its left; o.step draws the other series as filled steps; o.idle is a message shown in the plot when no shown value is above 0 (squeezed to fit a narrow plot), and applies only together with one of the other styles. A missing value leaves a gap in all of them (a lone value between gaps of a plain line draws as a dot); values below 0 draw at 0; threshold lines draw only in a single shared band, so o.split leaves them out and with o.strip they draw in the band below the strip. The hover shows "peak N · avg N" for peak bars, redraws keep the styles and kitTsAppend(root, id, label, values, avgs) appends to the avg lists. A stacked chart takes o.joined (parts touch, with no 2 px gap) and a series may carry dim (drawn and shown in the legend at 35% opacity). Without these options charts render exactly as in 1.2.2. Ranked lists change for every caller: the rankHtml value column is 56 px wide (was 46 px), so values such as "1869 Wh" stay on one line, and the row actions sit 10 px further left to match.
- 1.4.0: with o.split, series that carry the same s.band share one band named by that text; with o.bars 'peak' their bars stack in series order, each starting at the peak of the one below it, solid to its average and faint to its peak, the band scaled to the stacked peaks (with o.ymax, parts starting at the cap are left out), and one idle line runs under slots where all of the band's shown values are 0. Series without a band keep a band each, as in 1.3. A stacked chart (mode 'stack') takes o.idleLine (true draws the muted idle line under slots whose shown values are all 0; missing values are not idle) and now shows the o.idle message too; redraws keep band, idleLine and idle (data-kit-ts carries idleLine only when true and idle only when a non-empty text). Charts without these options render exactly as in 1.3.0, except a stacked chart that already passed o.idle, which now shows its message.
