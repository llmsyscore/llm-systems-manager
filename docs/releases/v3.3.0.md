Debian and RHEL packages, Docker images (`ghcr.io/llmsyscore/llm-systems-manager:v3.3.0`) and the Homebrew tap (`brew install llmsyscore/tap/llm-systems-manager`) follow the same tag. After upgrading, restart the manager, then the alarm engine, and update your agents.

This release adds an online demo of the dashboard, shows how much benchmark speeds vary from run to run, records the conditions of every benchmark run, adds prompt cache and draft-token tiles for llama.cpp, and has Forecast watch prompt speed on its own.

---

## Spotlight

### Try the dashboard online

https://demo.llmsyscore.com runs the real dashboard in your browser with a sample fleet of four machines. Every tab fills in and the charts keep moving. An optional tour points out the main screens. Tower answers every suggested question with a sample answer.

### Benchmarks show their spread and their conditions

- **Spread beside every speed.** Report Card, Live bench and autotune show the range of the repeated runs under each headline speed. A new result inside the baseline range says "within baseline spread", and autotune no longer picks settings from a single measurement.
- **Run conditions.** Every benchmark result saves what it ran on: GPU and driver, CPU, memory, operating system, backend build, the full server command, the model file, context size and the GPU temperature, clocks and power at the start and end.
- **Compare two runs.** Each tool can put two runs of the same model side by side, with the differences highlighted.

### llama.cpp: prompt cache and draft tokens

The llama server card has two new tiles. **Prompt cache reuse** shows how much of each prompt was already cached. **Draft tokens accepted** shows how many tokens from a draft model or MTP were kept. Each tile shows a percent, or a word when there is nothing to show (Not reported, Not in use, Idle, Paused, Reset).

### Forecast watches prompt speed

Forecast's Throughput check now follows prompt processing speed and generation speed separately, each against its own benchmark baseline. A drop in prompt speed gets its own finding, graph and next step.

### Smaller improvements

- **Short install address:** `bash <(curl -fsSL https://get.llmsyscore.com/install.sh)`. The long GitHub address still works.
- **Smaller download.** The release tarball, packages and Homebrew installs leave out the demo, the website and the screenshots: about 3.6 MB instead of 35 MB.
- **Shorter README** with a short GIF and the tour video near the top. The GIF ends on all nine color themes side by side. The feature list moved to `docs/FEATURES.md`, and install details moved to `docs/DEPLOYMENT.md`.
- **Analytics improvements** in the install and daily reports.
- **Bug and feature forms** on GitHub ask for versions, install method, engine and GPU up front.

## Upgrade notes

- **Restart the manager, then the alarm engine.** Both versions changed.
- **Update your agents** with **Update all**. The agent changed, and the new llama.cpp tiles need it.
- No config changes are needed.
